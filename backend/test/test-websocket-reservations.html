📖 Hướng dẫn Test

Các bước test:

  1. Kết nối WebSocket: Click "Connect to WebSocket" để kết nối tới namespace /reservations
  2. Lấy JWT Token: Login qua API auth để lấy JWT token, paste vào ô JWT Token
  3. Điền thông tin: Nhập user_id, vehicle_id, station_id, scheduled_time
  4. Tạo reservation: Click "Create Reservation via API"
  5. Quan sát Event Log: Xem WebSocket event "reservation.created" được emit

Events được emit:

  • reservation.created - Khi có reservation mới được tạo

Payload structure:

{
  "reservationId": number,
  "stationId": number,
  "stationName": string,
  "scheduledTime": string (ISO),
  "batteryId": number,
  "vehicle": {
    "id": number,
    "vin": string,
    "batteryModel": string,
    "batteryType": string
  },
  "user": {
    "id": number,
    "username": string,
    "email": string,
    "phone": string
  }
}
